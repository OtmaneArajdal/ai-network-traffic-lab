4. Vérifier la liste : `README.md`, `notebooks/`, `scripts/`, `data/`, `assets/`, `docs/` et `results/` doivent être accessibles directement depuis la racine. Les fichiers cachés comme `.gitignore` peuvent nécessiter une sélection spécifique dans Windows.
